Current data on this browser

Export

Downloads everything as one JSON file: students, lessons, payments, curriculum, workbooks, books, material, templates, custom-field settings, and API keys. Keep this file as your master backup.

Move covers & PDFs to the cloud

Moves cover images and answer PDFs stored in the browser to Firebase Storage. Only links stay in the browser, so storage usage stays tiny even with hundreds of files. Sign-in required.

Recalculate lesson hours

Recalculates every lesson's hours from its amount using each student's hourly rate (rate ÷ duration). Standard students (₩40,000/h): ₩60,000 → 1.5h. One-off students (₩24,000/h): ₩24,000 → 1h. Zero-amount and cancelled lessons are left untouched.

Import

Replaces ALL data on this browser with the backup file's contents, then reloads the app. Use this to move your data to another browser, computer, or address (e.g. from Live Server to file).

Google Custom Search API (for cover image search)

Get an API key at console.cloud.google.com and a Search Engine ID (cx) at programmablesearchengine.google.com. 100 free queries per day.

Google Calendar (schedule compare — read only)

Needs an OAuth client ID (type "Web application") from console.cloud.google.com with this app's address as an authorised JavaScript origin, and the Google Calendar API enabled in the same project.

ClassDesk User Guide

What is ClassDesk?

An all-in-one class management tool for English reading tutors and home-library owners. Manage students, lessons, tuition, curriculum, workbooks, and your English book library in one place — and print library-style level labels for your books yourself.

  • No installation — open the app's web address in a browser (Chrome recommended). Works on PC, phone, and tablet.
  • Your data, your account — everything is saved in this browser first, so the app keeps working offline. Sign in with Google (Settings → Account) to sync across your devices; synced data is stored privately under your own account and no one else can see it.
  • Automation — auto-filled book info, auto-generated parent report messages, automatic level colors, and more to cut down repetitive work.

What each page does

Dashboard
Your starting screen — today's classes and to-dos at a glance.
Students
Student profiles — name, class days & times, contact info, notes. The base data every other page builds on.
Classes
The heart of lesson records. Log each session's content, homework, and books read, and auto-generate a parent report message from your Settings template, ready to copy.
Payments
Tuition management — payment records and a payment-notice message template.
Curriculum
A curriculum board for laying out lesson plans on a monthly calendar.
Workbooks
Workbook management — covers, progress, per-student assignment.
Books
Your English book library — see "Books in depth" below. The core page of this app.
Material
Teaching materials, aids, and printouts.
Settings
Report & payment templates, custom fields (hide/reorder/rename columns), backup, API keys, and this guide.

Books in depth — the book library

Adding a book: type the title in the search box at the top → Search → pick a result. Cover, author, publisher, and ISBN are filled in automatically, and an AR/Lexile lookup runs in the background. Authors that arrive in all caps (MARC BROWN) are automatically cleaned up to Marc Brown.

  • Category / Genre — choose the format (picture book, chapter book, …) and subject (Animals, Adventure, …) from dropdowns. If it's not listed, use "+ Custom…" to type your own. Genre is auto-mapped from Google's classification, and if you already have a book by the same author or in the same series, its classification is inherited automatically.
  • Automatic level — enter the AR Level and the color level (L1–L8) is shown automatically. Scale: Red L1 (AR 0.0–0.9) · Orange L2 (1.0–1.9) · Yellow L3 (2.0–2.4) · Green L4 (2.5–2.9) · Blue L5 (3.0–3.4) · Purple L6 (3.5–3.9) · Pink L7 (4.0–4.9) · Black L8 (5.0+)
  • Search AR level / Search Lexile — if the automatic lookup can't find it, one click opens arbookfind.com / a Google search.
  • Search Google Images — for when you need a cleaner cover image. An image search opens with the title already copied to your clipboard; paste the image you find into the cover box.
  • Filter & search — filter by category, genre, AR range, level, Lexile, and label-print status. The search box matches title, author, publisher, ISBN, genre, and notes.

Label printing — supplies and steps

Supplies (two Glorytech label sheets):

  • SC9178 — for cover labels. 30×21mm, 78 cells per A4 sheet (6 columns × 13 rows). A mini cover to stick on the front of the book.
  • WP9140 — for info labels. 47×26.9mm, 40 cells per A4 sheet (4 columns × 10 rows). Color band (level) + title + author + AR/Lexile + category + ownership mark (library name — change it in Settings → Templates).

Printing steps:

  1. In Books, select the books with checkboxes → click the Covers or Info button at the top
  2. Enter the starting cell number — 1 for a fresh sheet, or the next free cell on a partly used sheet. Counting direction: cover labels run vertically (top→bottom), info labels run horizontally (left→right).
  3. Check the layout in the preview (dotted lines = label cell borders; they don't print) → Print
  4. Browser print settings: Paper A4 · Margins None · Scale 100% (turn off Fit to page) · under More settings, check Background graphics (needed for the color bands)
  5. If the print came out well, click ✓ Mark printed → the list records the labels as printed

Print tracking: a green C / I badge in the list means that label has been printed (hover to see the date); click it to toggle printed↔not printed. Use the "Cover not printed" filter to print only newly added books. Test prints leave no record unless you click Mark printed.

Paper-feed tip: every printer feeds differently. Draw an X on a plain A4 sheet, print once to see which side it lands on, then load the label side facing that way. The top and bottom margins of the label sheet differ, so always load it the same way up too.

Parent reports & payment messages

Create your wording once in Settings → Templates, and messages are generated with the lesson record filled in automatically (placeholders like [student_name], [topic], [hw_page], [books_read]). Copy and send via KakaoTalk or any messenger.

Customizing the screens

In Settings → Custom Fields you can reorder columns (drag), rename them (click), and hide them (uncheck) on every page, and add your own fields. Hidden fields still always appear in the edit dialog, so data entry is unaffected.

Automatic search setup (API Keys) — optional

Book info search (Google Books) works out of the box with no setup. To use image search (🔍) and automatic AR/Lexile lookup, register two things under Settings → API Keys:

  1. Google API key — create one in the Google Cloud Console, enable the "Custom Search API", and include it in the key's API restrictions.
  2. Search Engine ID (cx) — issued when you create a search engine at programmablesearchengine.google.com.

After registering, use the test button on the API Keys tab to confirm the connection. The free quota is 100 requests per day. Opening the file directly via file:/// may be blocked depending on your key restrictions — see the FAQ below.

Where your data lives — please read

  • Data is stored in this browser. As long as you use the same computer and browser, your data survives even when you replace the file with a new version.
  • To move to another computer or switch browsers, download a file via Settings → Backup → Export and Import it in the new environment.
  • If you clear site data in your browser's "Clear browsing data", all data is gone. Regular Export backups are strongly recommended.

Cloud sync

Sign in with your Google Account in Settings → Account and all your devices (PC, phone, tablet) share the same data in real time. It runs automatically — no extra buttons.

How do I turn it on?
Sign in once on each device — that's all. Your cloud data appears within a few seconds and from then on every change made anywhere shows up everywhere.
What if two devices edit at the same time?
Each student, lesson and book is synced on its own, so changes to different items never interfere. If the very same item is edited on two devices, the more recent edit wins. Deleted items stay deleted — an old copy on another device can't bring them back.
Where are covers and PDFs stored?
In Firebase Storage (the cloud); only the link stays in the browser. That's why you can register hundreds of books and PDFs without worrying about space. For older data, click Move covers & PDFs to cloud in Settings → Backup once.
What if my internet goes down?
The app keeps working as usual. Changes are saved to this browser first and queued; they upload automatically when the connection returns — even if you closed the app in between.
Where do I see sync status?
Settings → Account shows "✓ Synced (time)". If a sync failure message persists, check your sign-in status and internet connection.
Do I still need backups?
The cloud acts as a copy, but accidental deletions sync too. A monthly Export backup is still recommended.

Reading page — books read per student

Built automatically from the Books read entries you record in each lesson. Pick a student and a period: you get books read, the average AR level (with the change against the previous period), the current level (average of the last five books), an AR-over-time chart, and the list of books. Print report prints just this page for a parent meeting.

A book shows "not in the Books library"
The title typed in the lesson doesn't match any book in Books, so it has no AR level and is left out of the averages. Add the book to Books (or fix the spelling in the lesson) and it links up on its own.
Which lessons count?
Every lesson except cancelled ones. Double-click a row on the Reading page to open that lesson.

Schedule changes

A student drops one of two weekly classes (e.g. keeps Saturday, stops Sunday)
Students → edit the student → remove that slot with its trash icon → Save. You're asked from which date the change applies: pick the first day without that class. Everything before that date keeps the old schedule (and its billing); from that date on only the remaining class is generated.
A student's day or time changes
Same flow — change the day/time, Save, pick the effective date. Choose "Apply to everything" only for a correction of a typo, never for a real change.
Moving one class to another day (make-up class)
On a PC, drag the class chip onto the new day in Classes. On a tablet or phone, tap the class → change the Date (and time if needed) → Save. The class then shows "(moved)" and its usual day stays empty for that week; "Reset to usual time" in the same dialog undoes the move.
Comparing with Google Calendar
Classes → Google reads your Google Calendar for the month on screen and shows only the differences: a lesson only in Google ("Add lesson"), only in the app ("Cancel in app"), or at a different time ("Use Google time"). Students are recognised by their name, Korean name, or the aliases on their card — when a title isn't recognised, pick the student once and that title is remembered. The first time a calendar colour appears you say what it is (your own lesson, a flat ₩/hour lesson, or not a lesson). Nothing is written to Google, and nothing changes in the app until you press a button. Set-up lives in Settings → API Keys → Google Calendar.

Working with the lists

I want to resize columns
Hover over the gray vertical line between column headers — it turns green. Drag left or right. Adjusted widths are saved on this device. Double-click to reset.
How do I edit a row quickly?
Double-click any row in any list to open the edit dialog. Today's classes on the Dashboard work the same way.

Cover images

The cover is sideways
In the edit dialog, click the ↻ 90° button below the cover. Each click rotates it clockwise, and after saving it appears rotated in the list and on printed labels too. Works the same for uploaded images and Google covers.
Typing authors/illustrators every time is tedious
Type a few letters and matching names you've entered before appear below for one-click selection. Publishers work the same way.

Frequently asked questions

Printing

The printout splits across two pages
In print settings, check that Margins is None, paper is A4, and Scale is 100%.
The color bands don't print
Check Background graphics under More settings in the print dialog.
The print is off by a few millimeters from the labels
Printer feed tolerance. Snug the paper guides against the sheet and check which way you loaded it (front/back, top/bottom). The top and bottom margins differ, so loading it rotated 180° shifts everything by about 2mm.
It prints on the back of the sheet
A feed-direction issue. Draw an X on a plain A4 sheet, test-print to see which side it lands on, then load the label side facing that way.
Cover labels print with a white border
That's scan margin baked into the image file itself. Automatic trimming is attempted, but if it remains, replace the cover with a cleaner one via Search Google Images.
I clicked Mark printed but nothing changed
The print tab must still be connected to the original ClassDesk tab. Click it while the ClassDesk tab is still open. If you missed it, click the C/I badge in the list directly to mark it.

Automatic search · API

AR/Lexile isn't found automatically
Not every book is in the databases. Check via the Search AR level / Search Lexile links and enter it manually.
arbookfind shows "ATOS Book Level" instead of "AR Level"
They're the same value. ATOS is the official name for AR levels — enter that number in the AR Level field.
The image search button says "Search failed (HTTP 403)"
A Google API configuration issue. Check that ① the Custom Search API is enabled in the Google Cloud Console, and ② the API key's "API restrictions" include the Custom Search API. Then save both the API key and the Search Engine ID (cx) in Settings → API Keys.
I get "Requests from referer null are blocked"
Happens when the file is opened directly via file:///. Open it through a local server (127.0.0.1, e.g. VSCode Live Server), or set the API key's "Application restrictions" to "None" in the Google Cloud Console.
Automatic search worked before but suddenly stopped (HTTP 429)
You've exceeded the Google Custom Search free quota (100 requests/day). It resets automatically the next day. On bulk-entry days, mix in manual entry.
The book I want doesn't appear in search results
Try searching title + author (e.g. "arthur snow marc brown"). Editions registered by Korean distributors sometimes arrive with things like "(CD included)" in the title — just clean up the title after importing.

Other

Dates and weekdays differ from my computer's clock
ClassDesk's "today" is always Korea Standard Time (KST). Even if you open it abroad or your computer uses a different timezone, class schedules are computed in Korean time.
A field is missing in the edit dialog
The edit dialog always shows every field. Custom Fields hiding only applies to list columns. If it's still missing, check whether the file is an old version.
What happens to my data when I replace the file with a new version?
It stays, as long as it's the same computer and browser — data lives in the browser, not in the file. With cloud sync on, there's a copy in the cloud too. To be safe, Export before replacing.
I deleted something and it came back moments later
An old-version bug, fixed in the current version. If it still happens, check whether another device has an old version of the file open — every device should use the same up-to-date address (amber67-git.github.io/classdesk).
I deleted something by mistake
Right after deleting, an Undo button appears at the bottom for 6 seconds. If you missed it, you can recover by Importing a backup file.
How do I put ClassDesk on my phone/tablet home screen?
Open the ClassDesk address, then — Android (Chrome): menu ⋮ → Add to home screen (or Install app). iPhone/iPad (Safari): Share button → Add to Home Screen. It then opens full-screen like an app, and still opens without internet. The installed app may get its own storage, separate from the browser — if it shows the sample students (e.g. a Friday class for a student who moved to Thursday) and no payment marks, it simply isn't signed in yet: sign in once inside it (Settings → Account) and your cloud data replaces the samples.
Why are the amounts on the Dashboard hidden (₩ •••••)?
Privacy — so students can't see tuition or who hasn't paid. Tap the small eye icon in the "Expected (month)" card to reveal amounts and Paid/Unpaid badges. On phones and tablets they are hidden again every time you leave and reopen the app. On a PC they're shown by default, and your Show/Hide choice is remembered.
Can I lock the Payments page on the tablet?
Yes — Settings → Account → Payments PIN. Once set, tablets and phones ask for the PIN before Payments opens or hidden amounts are revealed, and Payments locks again the moment you leave it. PCs never ask. The PIN is shared by every device signed in with your account, so set it once on the PC.
Can I change the app icon to my own logo?
Settings → Templates → App logo. It changes the sidebar logo and browser-tab icon on every signed-in device. On iPhone/iPad it also becomes the home-screen icon if you add the app after setting it. The Android home-screen icon is fixed at install time.
The app looks broken or outdated on my phone
The browser is remembering (caching) an old file. Visit the address with ?v=number appended, or in Chrome settings clear only "Cached images and files". Never clear "Cookies and site data" — that deletes the app's data (recoverable by signing back in if cloud sync is on).
