ClassDesk User Guide

What is ClassDesk?

An all-in-one class management tool for private tutors: students, timetable, lesson records, tuition, reports, curriculum and teaching materials in one place, on PC, tablet and phone, with the repetitive parts automated — parent messages, payment requests, fee reminders, Google Calendar comparison. It was first built for an English reading class with its own home library, so it also keeps a book library with AR/Lexile levels and prints library-style level labels.

Where it is going. ClassDesk is being shaped into a product that any tutor, in any subject, can run their classes with and shape to their own way of teaching: choose or build a curriculum style (which sections a lesson record has, how the curriculum board is laid out, what the parent report says), set up the workspace (name, currency, time zone, default fee, categories), and keep the English-reading features — Reading, AR levels, book labels — as optional presets rather than built-ins. The settings that exist today (Custom Fields, message templates, logo, backup, cloud sync) are the first pieces of that; the rest is listed under "What's new" as it lands.

  • No installation — open the app's web address in a browser (Chrome recommended). Works on PC, phone, and tablet.
  • Your data, your account — everything is saved in this browser first, so the app keeps working offline. Sign in with Google (Settings → Account) to sync across your devices; synced data is stored privately under your own account and no one else can see it.
  • Automation — auto-filled book info, auto-generated parent report messages, automatic level colors, and more to cut down repetitive work.

Books in depth — the book library

Adding a book: type the title in the search box at the top → Search → pick a result. Cover, author, publisher, and ISBN are filled in automatically, and an AR/Lexile lookup runs in the background. Authors that arrive in all caps (MARC BROWN) are automatically cleaned up to Marc Brown.

  • Category / Genre — choose the format (picture book, chapter book, …) and subject (Animals, Adventure, …) from dropdowns. If it's not listed, use "+ Custom…" to type your own. Genre is auto-mapped from Google's classification, and if you already have a book by the same author or in the same series, its classification is inherited automatically.
  • Automatic level — enter the AR Level and the color level (L1–L8) is shown automatically. Scale: Red L1 (AR 0.0–0.9) · Orange L2 (1.0–1.9) · Yellow L3 (2.0–2.4) · Green L4 (2.5–2.9) · Blue L5 (3.0–3.4) · Purple L6 (3.5–3.9) · Pink L7 (4.0–4.9) · Black L8 (5.0+)
  • Search AR level / Search Lexile — if the automatic lookup can't find it, one click opens arbookfind.com / a Google search.
  • Search Google Images — for when you need a cleaner cover image. An image search opens with the title already copied to your clipboard; paste the image you find into the cover box.
  • Filter & search — filter by category, genre, AR range, level, Lexile, and label-print status. The search box matches title, author, publisher, ISBN, genre, and notes.

Label printing — supplies and steps

Supplies (two Glorytech label sheets):

  • SC9178 — for cover labels. 30×21mm, 78 cells per A4 sheet (6 columns × 13 rows). A mini cover to stick on the front of the book.
  • WP9140 — for info labels. 47×26.9mm, 40 cells per A4 sheet (4 columns × 10 rows). Color band (level) + title + author + AR/Lexile + category + ownership mark (library name — change it in Settings → Templates → Workspace).

Printing steps:

  1. In Books, select the books with checkboxes → click the Covers or Info button at the top
  2. Enter the starting cell number — 1 for a fresh sheet, or the next free cell on a partly used sheet. Counting direction: cover labels run vertically (top→bottom), info labels run horizontally (left→right).
  3. Check the layout in the preview (dotted lines = label cell borders; they don't print) → Print
  4. Browser print settings: Paper A4 · Margins None · Scale 100% (turn off Fit to page) · under More settings, check Background graphics (needed for the color bands)
  5. If the print came out well, click ✓ Mark printed → the list records the labels as printed

Print tracking: a green C / I badge in the list means that label has been printed (hover to see the date); click it to toggle printed↔not printed. Use the "Cover not printed" filter to print only newly added books. Test prints leave no record unless you click Mark printed.

Paper-feed tip: every printer feeds differently. Draw an X on a plain A4 sheet, print once to see which side it lands on, then load the label side facing that way. The top and bottom margins of the label sheet differ, so always load it the same way up too.

Automatic search setup (API Keys) — optional

Book info search (Google Books) works out of the box with no setup. To use image search (🔍) and automatic AR/Lexile lookup, register two things under Settings → API Keys:

  1. Google API key — create one in the Google Cloud Console, enable the "Custom Search API", and include it in the key's API restrictions.
  2. Search Engine ID (cx) — issued when you create a search engine at programmablesearchengine.google.com.

After registering, use the test button on the API Keys tab to confirm the connection. The free quota is 100 requests per day. Opening the file directly via file:/// may be blocked depending on your key restrictions — see the FAQ below.

Where your data lives — please read

  • Data is stored in this browser. As long as you use the same computer and browser, your data survives even when you replace the file with a new version.
  • To move to another computer or switch browsers, download a file via Settings → Backup → Export and Import it in the new environment.
  • If you clear site data in your browser's "Clear browsing data", all data is gone. Regular Export backups are strongly recommended.

Cloud sync

Sign in with your Google Account in Settings → Account and all your devices (PC, phone, tablet) share the same data in real time. It runs automatically — no extra buttons.

How do I turn it on?
Sign in once on each device — that's all. Your cloud data appears within a few seconds and from then on every change made anywhere shows up everywhere.
What if two devices edit at the same time?
Each student, lesson and book is synced on its own, so changes to different items never interfere. If the very same item is edited on two devices, the more recent edit wins. Deleted items stay deleted — an old copy on another device can't bring them back.
Where are covers and PDFs stored?
In Firebase Storage (the cloud); only the link stays in the browser. That's why you can register hundreds of books and PDFs without worrying about space. For older data, click Move covers & PDFs to cloud in Settings → Backup once.
What if my internet goes down?
The app keeps working as usual. Changes are saved to this browser first and queued; they upload automatically when the connection returns — even if you closed the app in between.
Where do I see sync status?
Settings → Account shows "✓ Synced (time)". If a sync failure message persists, check your sign-in status and internet connection.
Do I still need backups?
The cloud acts as a copy, but accidental deletions sync too. A monthly Export backup is still recommended.

Reading page — books read per student

Built automatically from the Books read entries you record in each lesson. Pick a student and a period: you get books read, the average AR level (with the change against the previous period), the current level (average of the last five books), an AR-over-time chart, and the list of books. Print report prints just this page for a parent meeting.

A book shows "not in the Books library"
The title typed in the lesson doesn't match any book in Books, so it has no AR level and is left out of the averages. Add the book to Books (or fix the spelling in the lesson) and it links up on its own.
Which lessons count?
Every lesson except cancelled ones. Double-click a row on the Reading page to open that lesson.

Schedule changes

A student drops one of two weekly classes (e.g. keeps Saturday, stops Sunday)
Students → edit the student → remove that slot with its trash icon → Save. You're asked from which date the change applies: pick the first day without that class. Everything before that date keeps the old schedule (and its billing); from that date on only the remaining class is generated.
A student's day or time changes
Same flow — change the day/time, Save, pick the effective date. Choose "Apply to everything" only for a correction of a typo, never for a real change.
Moving one class to another day (make-up class)
On a PC, drag the class chip onto the new day in Classes. On a tablet or phone, tap the class → change the Date (and time if needed) → Save. The class then shows "(moved)" and its usual day stays empty for that week; "Reset to usual time" in the same dialog undoes the move.
Comparing with Google Calendar
Classes → Google reads your Google Calendar for the month on screen and shows only the differences: a lesson only in Google ("Add lesson"), only in the app ("Cancel in app"), at a different time ("Use Google time"), or on a different day within the same week ("Move in app" — recorded as a moved class, not as a cancellation plus a new lesson, so the Payments summary does not count it as cancelled). Students are recognised by their name, Korean name, or the aliases on their card — when a title isn't recognised, pick the student once and that title is remembered. Only yellow (your own lessons) and green (platform lessons) events count; every other colour is ignored. Nothing is written to Google, and nothing changes in the app until you press a button. Set-up lives in Settings → API Keys → Google Calendar.

Frequently asked questions

Printing

The printout splits across two pages
In print settings, check that Margins is None, paper is A4, and Scale is 100%.
The color bands don't print
Check Background graphics under More settings in the print dialog.
The print is off by a few millimeters from the labels
Printer feed tolerance. Snug the paper guides against the sheet and check which way you loaded it (front/back, top/bottom). The top and bottom margins differ, so loading it rotated 180° shifts everything by about 2mm.
It prints on the back of the sheet
A feed-direction issue. Draw an X on a plain A4 sheet, test-print to see which side it lands on, then load the label side facing that way.
Cover labels print with a white border
That's scan margin baked into the image file itself. Automatic trimming is attempted, but if it remains, replace the cover with a cleaner one via Search Google Images.
I clicked Mark printed but nothing changed
The print tab must still be connected to the original ClassDesk tab. Click it while the ClassDesk tab is still open. If you missed it, click the C/I badge in the list directly to mark it.

Automatic search · API

AR/Lexile isn't found automatically
Not every book is in the databases. Check via the Search AR level / Search Lexile links and enter it manually.
arbookfind shows "ATOS Book Level" instead of "AR Level"
They're the same value. ATOS is the official name for AR levels — enter that number in the AR Level field.
The image search button says "Search failed (HTTP 403)"
A Google API configuration issue. Check that ① the Custom Search API is enabled in the Google Cloud Console, and ② the API key's "API restrictions" include the Custom Search API. Then save both the API key and the Search Engine ID (cx) in Settings → API Keys.
I get "Requests from referer null are blocked"
Happens when the file is opened directly via file:///. Open it through a local server (127.0.0.1, e.g. VSCode Live Server), or set the API key's "Application restrictions" to "None" in the Google Cloud Console.
Automatic search worked before but suddenly stopped (HTTP 429)
You've exceeded the Google Custom Search free quota (100 requests/day). It resets automatically the next day. On bulk-entry days, mix in manual entry.
The book I want doesn't appear in search results
Try searching title + author (e.g. "arthur snow marc brown"). Editions registered by Korean distributors sometimes arrive with things like "(CD included)" in the title — just clean up the title after importing.

Other

Dates and weekdays differ from my computer's clock
ClassDesk counts "today" in the workspace time zone — Korea (KST) unless you change it in Settings → Templates → Workspace. Opened abroad or on a computer set to another zone, class days, the payment months and Google Calendar times still follow that zone.
I don't teach reading — can I hide Reading and Books?
Settings → Templates → Features → Any subject. The Reading and Books pages leave the menu, the lesson card loses its "Books read" section, and the Curriculum columns become Unit, Materials and Homework (Books and Grammar hidden). You can also switch each page and lesson section on its own. Nothing is deleted: switch it back on and everything is still there.
Can I use another currency or change the default fee?
Settings → Templates → Workspace. The default hourly fee is filled in for a new student or lesson (each student's own rate still wins). Currency only changes how amounts are shown (₩, $, £, €, ¥ …) — numbers already saved are not converted. Changing the currency or time zone reloads the app.
A field is missing in the edit dialog
The edit dialog always shows every field. Custom Fields hiding only applies to list columns. If it's still missing, check whether the file is an old version.
What happens to my data when I replace the file with a new version?
It stays, as long as it's the same computer and browser — data lives in the browser, not in the file. With cloud sync on, there's a copy in the cloud too. To be safe, Export before replacing.
I deleted something and it came back moments later
An old-version bug, fixed in the current version. If it still happens, check whether another device has an old version of the file open — every device should use the same up-to-date address (amber67-git.github.io/classdesk).
I deleted something by mistake
Right after deleting, an Undo button appears at the bottom for 6 seconds. If you missed it, you can recover by Importing a backup file.
How do I put ClassDesk on my phone/tablet home screen?
Open the ClassDesk address, then — Android (Chrome): menu ⋮ → Add to home screen (or Install app). iPhone/iPad (Safari): Share button → Add to Home Screen. It then opens full-screen like an app, and still opens without internet. On iPhone/iPad the home-screen app gets its own storage, separate from Safari (on Android it shares Chrome's). Signing in brings back only what is in the cloud; anything you entered in Safari without being signed in stays there, so Export it in Safari (Settings → Backup → Export) and Import it in the home-screen app. If the new app shows the sample students (e.g. a Friday class for a student who moved to Thursday) and no payment marks, it simply isn't signed in yet: sign in once inside it (Settings → Account) and your cloud data replaces the samples. Android says "This app is already installed" but ClassDesk is not on the phone (or "Could not open app")? Android Chrome currently installs only one web app per site address (a known Chrome bug), and ClassDesk shares amber67-git.github.io with the owner's other apps, so another app from that address is installed. Type chrome://webapks in Chrome to see which. First Export a backup (Settings → Backup → Export). Then remove that app (phone Settings → Apps → that app → Uninstall) — if Chrome offers to delete site data or storage, say no: that would erase ClassDesk's data too. Then install ClassDesk from Chrome. StudyDesk moved to its own address (amber-studydesk.netlify.app) on Nov 4, 2026, so a StudyDesk installed from there no longer gets in the way. iPhone/iPad and ClassDesk in a PC browser tab are not affected. An app installed on a PC before v116 keeps working but stops getting icon/name updates; to refresh it, Export a backup, remove it (Chrome: chrome://apps → right-click ClassDesk → Remove, leaving "Also clear data from Chrome" unticked) and install again.
Does anything remind me about fees that never arrived?
Yes. Last month's fees are expected by the 10th of this month; from the 11th on, if any of them are still outstanding, a popup lists who owes how much when you open the app, and it comes back every 5 days until you mark the money as received. Only the month immediately before the current one is checked, so it stops on its own when the month rolls over. On phones and tablets the names and amounts are left out of the popup — the same privacy rule the Dashboard and the Payments PIN follow — and "Open Payments" takes you straight to that month. The 5-day pause is remembered per device, so dismissing it on the PC doesn't silence the tablet.
Why are the amounts on the Dashboard hidden (₩ •••••)?
Privacy — so students can't see tuition or who hasn't paid. Tap the small eye icon in the "Expected (month)" card to reveal amounts and Paid/Unpaid badges. On phones and tablets they are hidden again every time you leave and reopen the app. On a PC they're shown by default, and your Show/Hide choice is remembered.
Can I lock the Payments page on the tablet?
Yes — Settings → Account → Payments PIN. Once set, tablets and phones ask for the PIN before Payments opens or hidden amounts are revealed, and Payments locks again the moment you leave it. PCs never ask. The PIN is shared by every device signed in with your account, so set it once on the PC.
A curriculum column is too narrow to read
Drag the thin line on the right edge of that column's heading — like Google Sheets. Double-click the line to fit the column to its text; the ↔ button at the right end of the heading row resets all widths. Each device remembers its own widths.
Editing the curriculum like a spreadsheet
On a tablet or computer: click a cell and type to replace it, or press Enter / F2 / double-click to change what is there (Alt+Enter starts a new line, Esc cancels). Enter, Tab and the arrow keys move; Shift+arrows or dragging selects several cells. Ctrl+C / V copy and paste — blocks from Google Sheets or Excel fill the cells, and rows past the end are added. Delete clears, Ctrl+Z / Y undo and redo. Rows: Alt+↑/↓ or drag ⠿ to move a row; right-click (or ⋮) to insert, duplicate or delete. Merge joins the selected cells (all, vertically or horizontally); a merged cell keeps the top-left text, and in a vertical merge every week in it shares that text. Moving a row never cuts a merge in half. The palette button colours cells, and Sort puts the rows back in month and week order. Style: Ctrl+B bold, Ctrl+I italic, Alt+Shift+5 strikethrough (or the B / I / S buttons). Notes: Shift+F2 or right-click → Insert note; a cell with a note has a small corner mark and shows the note when selected. Find and replace: Ctrl+F / H or 🔍 — matches are outlined, Enter goes to the next one, and Replace all can be undone in one step (month and week cells are found but not replaced). Filter hides rows by a column's values (only on this device, until you leave the page) and sorts the rows A → Z or Z → A by that column; rows held by a vertical merge stay together. Fill handle: drag the small green square at the corner of the selection down or up to repeat the cells with their colour and style; two week numbers (1, 2) carry on as 3, 4, 5. The line-height button clips each row to 3 lines or 1 line on this device. Every change is saved and synced straight away.
How do I bring my curriculum in from a spreadsheet?
Curriculum → Import. In Google Sheets, select the rows including the heading row and copy (Ctrl+C), then paste into the box — or use File → Download → CSV and choose that file. Columns are found by their headings: MONTH, 주제 / Topics, Workbook, Writing, Reading Books, Activities, ORT, Grammar, Note. A row holding only a year (2025) starts that year; a "[과학]"-style tag at the start of the 주제 cell becomes the category. The dialog shows what it found before anything changes, topics already in the app are only filled in (never duplicated), and Undo is offered right after.
Can I use the app in Korean?
Settings → Templates → Language: "Match the device language" (default), English or 한국어. The app reloads with the new language. Only the app's own words change — student names, notes and your message templates stay exactly as you typed them. Since v129 this Guide has a Korean version too and switches with the rest of the app.
Can I use a dark screen?
Settings → Templates → Appearance: "Match the device" (the default — dark when the phone or computer is set to dark, and it changes along with it), Light or Dark. It is set per device, so the classroom PC can stay light while your phone is dark. It is not part of a backup, and printed labels and reports always come out light.
Can I change the app icon to my own logo?
Settings → Templates → App logo. It changes the sidebar logo and browser-tab icon on every signed-in device. On iPhone/iPad it also becomes the home-screen icon if you add the app after setting it. The Android home-screen icon is fixed at install time.
Removing another app from the phone (StudyDesk etc.)
ClassDesk shares its web address (amber67-git.github.io) with older copies of the other apps, and everything stored under one address is wiped together. To remove one of those older apps: phone Settings → Apps → that app → Uninstall only. Never tap "Clear storage" / "Clear site data" — it would erase ClassDesk's data on this phone too (signing back in brings the cloud copy back, but anything not yet synced is lost). Afterwards, typing chrome://webapks in Chrome should still list ClassDesk, with the Manifest Id https://amber67-git.github.io/classdesk/app (a copy installed before v116 shows https://amber67-git.github.io/ — see "How do I put ClassDesk on my phone/tablet home screen?" above).
The app looks broken or outdated on my phone
The browser is remembering (caching) an old file. Visit the address with ?v=number appended, or in Chrome settings clear only "Cached images and files". Never clear "Cookies and site data" — that deletes the app's data (recoverable by signing back in if cloud sync is on).

ClassDesk는 어떤 앱인가요?

개인 과외·공부방 선생님을 위한 올인원 수업 관리 도구입니다. 학생, 시간표, 수업 기록, 수업료, 보고서, 커리큘럼, 교재·교구를 한곳에서 PC·태블릿·휴대폰으로 관리하고, 반복되는 일은 자동으로 처리합니다 — 학부모 메시지, 수업료 안내, 미납 알림, Google 캘린더 비교. 처음에는 자체 도서관을 갖춘 영어 리딩 수업을 위해 만들어져서, AR/Lexile 레벨이 붙은 도서 목록과 도서관식 레벨 라벨 인쇄 기능도 들어 있습니다.

앞으로의 방향. ClassDesk는 어떤 과목의 어떤 선생님이든 자기 수업 방식에 맞춰 쓸 수 있는 제품으로 다듬어지고 있습니다. 커리큘럼 스타일(수업 기록의 항목, 커리큘럼 보드 구성, 학부모 보고서 내용)을 고르거나 직접 만들고, 작업 공간(이름, 통화, 시간대, 기본 수업료, 카테고리)을 설정하며, 독서·AR 레벨·도서 라벨 같은 영어 리딩 기능은 기본 기능이 아니라 선택형 프리셋으로 두는 방향입니다. 지금 있는 설정(사용자 항목, 메시지 템플릿, 로고, 백업, 클라우드 동기화)이 그 첫 단계이고, 나머지는 완성되는 대로 "새로운 기능"에 적어 둡니다.

  • 설치 필요 없음 — 브라우저(Chrome 권장)에서 앱 주소를 열면 됩니다. PC, 휴대폰, 태블릿 모두 됩니다.
  • 내 데이터는 내 계정에 — 모든 내용은 먼저 이 브라우저에 저장되므로 인터넷이 끊겨도 앱은 계속 동작합니다. Google로 로그인하면(설정 → 계정) 여러 기기에서 동기화되며, 동기화된 데이터는 내 계정에만 저장되어 다른 사람은 볼 수 없습니다.
  • 자동화 — 도서 정보 자동 입력, 학부모 보고 메시지 자동 작성, 레벨 색상 자동 지정 등으로 반복 작업을 줄입니다.

도서 자세히 보기 — 도서 목록

책 추가: 위쪽 검색창에 제목 입력 → 검색 → 결과 선택. 표지, 저자, 출판사, ISBN이 자동으로 채워지고, AR/Lexile 조회는 뒤에서 진행됩니다. 대문자로만 들어온 저자명(MARC BROWN)은 Marc Brown으로 자동 정리됩니다.

  • 카테고리 / 장르 — 형식(그림책, 챕터북 …)과 주제(동물, 모험 …)를 목록에서 고릅니다. 목록에 없으면 "+ 직접 입력…"으로 적으면 됩니다. 장르는 Google 분류에서 자동으로 연결되고, 같은 저자나 같은 시리즈의 책이 이미 있으면 그 분류를 자동으로 이어받습니다.
  • 레벨 자동 표시 — AR 레벨을 입력하면 색상 레벨(L1–L8)이 자동으로 표시됩니다. 기준: 빨강 L1 (AR 0.0–0.9) · 주황 L2 (1.0–1.9) · 노랑 L3 (2.0–2.4) · 초록 L4 (2.5–2.9) · 파랑 L5 (3.0–3.4) · 보라 L6 (3.5–3.9) · 분홍 L7 (4.0–4.9) · 검정 L8 (5.0+)
  • AR 레벨 검색 / Lexile 검색 — 자동 조회로 찾지 못하면 한 번 눌러 arbookfind.com / Google 검색을 엽니다.
  • Google 이미지 검색 — 더 깨끗한 표지가 필요할 때 씁니다. 제목이 클립보드에 복사된 채로 이미지 검색이 열리니, 찾은 이미지를 표지 칸에 붙여 넣으세요.
  • 필터와 검색 — 카테고리, 장르, AR 범위, 레벨, Lexile, 라벨 인쇄 여부로 거를 수 있습니다. 검색창은 제목, 저자, 출판사, ISBN, 장르, 메모를 찾습니다.

라벨 인쇄 — 준비물과 순서

준비물 (글로리텍 라벨지 두 종류):

  • SC9178 — 표지 라벨용. 30×21mm, A4 한 장에 78칸(6열 × 13행). 책 앞표지에 붙이는 작은 표지입니다.
  • WP9140 — 정보 라벨용. 47×26.9mm, A4 한 장에 40칸(4열 × 10행). 색상 띠(레벨) + 제목 + 저자 + AR/Lexile + 카테고리 + 소유 표시(도서관 이름 — 설정 → 템플릿 → 작업 공간에서 바꿉니다).

인쇄 순서:

  1. 도서에서 체크박스로 책을 고른 뒤 → 위쪽의 표지 또는 정보 버튼을 누릅니다
  2. 시작 칸 번호를 입력합니다 — 새 라벨지는 1, 쓰다 남은 라벨지는 다음 빈칸 번호. 세는 방향: 표지 라벨은 세로(위→아래), 정보 라벨은 가로(왼쪽→오른쪽)입니다.
  3. 미리보기에서 배치를 확인하고(점선 = 라벨 칸 경계, 인쇄되지 않음) → 인쇄
  4. 브라우저 인쇄 설정: 용지 A4 · 여백 없음 · 배율 100%(페이지에 맞추기 끄기) · 설정 더보기에서 배경 그래픽 체크(색상 띠에 필요)
  5. 잘 나왔으면 ✓ 인쇄 완료 표시를 누릅니다 → 목록에 라벨 인쇄 기록이 남습니다

인쇄 기록: 목록의 초록색 C / I 배지는 해당 라벨을 인쇄했다는 뜻입니다(마우스를 올리면 날짜가 보입니다). 배지를 누르면 인쇄됨↔미인쇄가 바뀝니다. "표지 라벨 미인쇄" 필터로 새로 들어온 책만 골라 인쇄할 수 있습니다. 시험 인쇄는 인쇄 완료 표시를 누르지 않으면 기록이 남지 않습니다.

용지 넣는 요령: 프린터마다 용지가 들어가는 방향이 다릅니다. 빈 A4에 X를 그려 한 번 인쇄해 보고 어느 면에 찍히는지 확인한 뒤, 라벨 면을 그쪽으로 넣으세요. 라벨지는 위아래 여백이 달라서 항상 같은 방향으로 넣어야 합니다.

자동 검색 설정 (API 키) — 선택 사항

도서 정보 검색(Google Books)은 따로 설정하지 않아도 됩니다. 이미지 검색(🔍)과 AR/Lexile 자동 조회를 쓰려면 설정 → API 키에 두 가지를 등록하세요:

  1. Google API 키 — Google Cloud Console에서 만들고, "Custom Search API"를 사용 설정한 다음 키의 API 제한에 포함합니다.
  2. 검색엔진 ID (cx) — programmablesearchengine.google.com에서 검색엔진을 만들면 발급됩니다.

등록한 뒤 API 키 탭의 테스트 버튼으로 연결을 확인하세요. 무료 사용량은 하루 100회입니다. file:///로 파일을 직접 열면 키 제한 설정에 따라 막힐 수 있습니다 — 아래 자주 묻는 질문을 참고하세요.

데이터는 어디에 저장되나요 — 꼭 읽어 주세요

  • 데이터는 이 브라우저 안에 저장됩니다. 같은 컴퓨터, 같은 브라우저를 쓰는 한 파일을 새 버전으로 바꿔도 데이터는 그대로입니다.
  • 다른 컴퓨터로 옮기거나 브라우저를 바꿀 때는 설정 → 백업 → 내보내기로 파일을 받은 뒤 새 환경에서 가져오기하세요.
  • 브라우저의 "인터넷 사용 기록 삭제"에서 사이트 데이터를 지우면 모든 데이터가 사라집니다. 정기적으로 내보내기 백업을 해 두시길 강력히 권합니다.

클라우드 동기화

설정 → 계정에서 Google 계정으로 로그인하면 모든 기기(PC, 휴대폰, 태블릿)가 같은 데이터를 실시간으로 공유합니다. 자동으로 동작하며 따로 누를 버튼은 없습니다.

어떻게 켜나요?
기기마다 한 번씩 로그인하면 끝입니다. 몇 초 안에 클라우드 데이터가 나타나고, 그 뒤로는 어느 기기에서 바꾸든 모든 기기에 반영됩니다.
두 기기에서 동시에 고치면 어떻게 되나요?
학생, 수업, 책은 하나하나 따로 동기화되므로 서로 다른 항목을 고치면 부딪히지 않습니다. 같은 항목을 두 기기에서 고치면 나중에 고친 쪽이 남습니다. 삭제한 항목은 삭제된 채로 유지되며, 다른 기기에 남은 옛 사본이 되살리지 않습니다.
표지와 PDF는 어디에 저장되나요?
Firebase Storage(클라우드)에 저장되고 브라우저에는 링크만 남습니다. 그래서 책과 PDF를 수백 개 등록해도 용량 걱정이 없습니다. 예전 데이터는 설정 → 백업에서 표지와 PDF를 클라우드로 옮기기를 한 번 누르세요.
인터넷이 끊기면요?
앱은 평소처럼 동작합니다. 바뀐 내용은 먼저 이 브라우저에 저장되어 대기하다가, 연결이 돌아오면 자동으로 올라갑니다 — 그 사이에 앱을 닫았더라도 마찬가지입니다.
동기화 상태는 어디서 보나요?
설정 → 계정에 "✓ 동기화됨 (시각)"이 표시됩니다. 동기화 실패 메시지가 계속 보이면 로그인 상태와 인터넷 연결을 확인하세요.
그래도 백업이 필요한가요?
클라우드가 사본 역할을 하지만, 실수로 지운 것도 그대로 동기화됩니다. 한 달에 한 번 내보내기 백업을 여전히 권합니다.

독서 화면 — 학생별 읽은 책

수업마다 기록한 읽은 책으로 자동으로 만들어집니다. 학생과 기간을 고르면 읽은 책 수, 평균 AR 레벨(이전 기간 대비 변화 포함), 현재 레벨(최근 다섯 권 평균), 기간별 AR 그래프, 책 목록이 나옵니다. 보고서 인쇄는 학부모 상담용으로 이 화면만 인쇄합니다.

"도서 목록에 없음"이라고 나오는 책이 있어요
수업에 적은 제목이 도서의 어떤 책과도 맞지 않아 AR 레벨이 없고, 그래서 평균에서 빠진 것입니다. 그 책을 도서에 추가하거나 수업의 철자를 고치면 저절로 연결됩니다.
어떤 수업이 포함되나요?
취소된 수업을 뺀 모든 수업입니다. 독서 화면에서 행을 두 번 누르면 그 수업이 열립니다.

시간표 변경

주 2회 수업 중 하나를 그만둘 때 (예: 토요일은 계속, 일요일은 그만)
학생 → 학생 편집 → 그 시간 줄의 휴지통 아이콘으로 삭제 → 저장. 언제부터 적용할지 물으면 그 수업이 없어지는 첫날을 고르세요. 그 날짜 전까지는 예전 시간표(와 수업료)가 그대로이고, 그 날짜부터는 남은 수업만 만들어집니다.
학생의 요일이나 시간이 바뀔 때
같은 방법입니다 — 요일·시간을 바꾸고 저장한 뒤 적용 날짜를 고르세요. "전체에 적용"은 오타를 고칠 때만 쓰고, 실제 변경에는 쓰지 마세요.
수업 하나를 다른 날로 옮길 때 (보강)
PC에서는 수업 화면에서 수업 칩을 새 날짜로 끌어다 놓습니다. 태블릿이나 휴대폰에서는 수업을 눌러 → 날짜(필요하면 시간도)를 바꾸고 → 저장. 그 수업에는 "(이동)"이 표시되고 그 주의 원래 요일은 비어 있게 됩니다. 같은 창의 "원래 시간으로 되돌리기"로 이동을 취소할 수 있습니다.
Google 캘린더와 비교하기
수업 → Google은 화면에 보이는 달의 Google 캘린더를 읽어 다른 점만 보여 줍니다: Google에만 있는 수업("수업 추가"), 앱에만 있는 수업("앱에서 취소"), 시간이 다른 수업("Google 시간 사용"), 같은 주 안에서 요일이 다른 수업("앱에서 이동" — 취소와 새 수업이 아니라 옮긴 수업으로 기록되므로 수업료 요약에서 취소로 세지 않습니다). 학생은 이름, 한글 이름, 학생 카드의 별칭으로 알아봅니다 — 알아보지 못한 제목은 학생을 한 번 골라 주면 기억합니다. 노란색(직접 하는 수업)과 초록색(플랫폼 수업) 일정만 세고, 다른 색은 모두 무시합니다. Google에는 아무것도 쓰지 않으며, 버튼을 누르기 전에는 앱에서도 아무것도 바뀌지 않습니다. 설정은 설정 → API 키 → Google 캘린더에 있습니다.

행을 빨리 고치려면요?
어느 목록이든 행을 두 번 누르면 편집 창이 열립니다. 대시보드의 오늘 수업도 같습니다.

편집 창에서 표지 아래의 ↻ 90° 버튼을 누르세요. 누를 때마다 시계 방향으로 돌아가고, 저장하면 목록과 인쇄 라벨에도 돌아간 모습으로 나옵니다. 올린 이미지와 Google 표지 모두 똑같이 됩니다.

몇 글자만 치면 전에 입력한 이름이 아래에 나타나 한 번에 고를 수 있습니다. 출판사도 같습니다.

자주 묻는 질문

인쇄

인쇄물이 두 쪽으로 나뉘어 나와요
인쇄 설정에서 여백 없음, 용지 A4, 배율 100%인지 확인하세요.
색상 띠가 인쇄되지 않아요
인쇄 창의 설정 더보기에서 배경 그래픽을 체크하세요.
라벨과 인쇄 위치가 몇 mm 어긋나요
프린터 급지 오차입니다. 용지 가이드를 라벨지에 딱 맞추고, 넣은 방향(앞/뒤, 위/아래)을 확인하세요. 위아래 여백이 달라서 180° 돌려 넣으면 전체가 2mm쯤 밀립니다.
라벨지 뒷면에 인쇄돼요
급지 방향 문제입니다. 빈 A4에 X를 그려 시험 인쇄로 어느 면에 찍히는지 확인한 뒤, 라벨 면을 그쪽으로 넣으세요.
표지 라벨에 흰 테두리가 생겨요
이미지 파일 자체에 스캔 여백이 들어 있는 경우입니다. 자동으로 잘라 보지만 그래도 남으면 Google 이미지 검색으로 더 깨끗한 표지로 바꾸세요.
인쇄 완료 표시를 눌렀는데 바뀌지 않아요
인쇄 탭이 원래 ClassDesk 탭과 연결되어 있어야 합니다. ClassDesk 탭이 열려 있는 동안 누르세요. 놓쳤다면 목록의 C/I 배지를 직접 눌러 표시하면 됩니다.

자동 검색 · API

AR/Lexile이 자동으로 찾아지지 않아요
모든 책이 데이터베이스에 있지는 않습니다. AR 레벨 검색 / Lexile 검색 링크로 확인해서 직접 입력하세요.
arbookfind에 "AR Level" 대신 "ATOS Book Level"이 나와요
같은 값입니다. ATOS가 AR 레벨의 공식 이름이니 그 숫자를 AR 레벨 칸에 입력하세요.
이미지 검색 버튼에 "Search failed (HTTP 403)"이 나와요
Google API 설정 문제입니다. ① Google Cloud Console에서 Custom Search API가 사용 설정되어 있는지, ② API 키의 "API 제한"에 Custom Search API가 들어 있는지 확인하세요. 그런 다음 설정 → API 키에 API 키와 검색엔진 ID(cx)를 모두 저장하세요.
"Requests from referer null are blocked"가 나와요
file:///로 파일을 직접 열었을 때 생깁니다. 로컬 서버(127.0.0.1, 예: VSCode Live Server)로 열거나, Google Cloud Console에서 API 키의 "애플리케이션 제한"을 "없음"으로 바꾸세요.
자동 검색이 잘 되다가 갑자기 안 돼요 (HTTP 429)
Google Custom Search 무료 사용량(하루 100회)을 넘었습니다. 다음 날 자동으로 풀립니다. 한꺼번에 많이 입력하는 날에는 직접 입력을 섞어 쓰세요.
찾는 책이 검색 결과에 안 나와요
제목 + 저자로 검색해 보세요(예: "arthur snow marc brown"). 국내 유통사가 등록한 판은 제목에 "(CD 포함)" 같은 말이 붙어 오기도 하니, 가져온 뒤 제목만 정리하면 됩니다.

기타

날짜와 요일이 컴퓨터 시계와 달라요
ClassDesk는 "오늘"을 작업 공간 시간대로 셉니다 — 설정 → 템플릿 → 작업 공간에서 바꾸지 않았다면 한국 시간(KST)입니다. 해외에서 열거나 다른 시간대로 맞춘 컴퓨터에서도 수업 요일, 수업료 달, Google 캘린더 시간은 그 시간대를 따릅니다.
리딩 수업이 아닌데 독서와 도서를 숨길 수 있나요?
설정 → 템플릿 → 기능 → 모든 과목. 독서와 도서 화면이 메뉴에서 빠지고, 수업 카드에서 "읽은 책" 항목이 사라지며, 커리큘럼 열은 단원·자료·숙제가 됩니다(도서·문법 열은 숨김). 화면과 수업 항목을 하나씩 켜고 끌 수도 있습니다. 지워지는 것은 없으니 다시 켜면 그대로 있습니다.
다른 통화를 쓰거나 기본 수업료를 바꿀 수 있나요?
설정 → 템플릿 → 작업 공간. 기본 시간당 수업료는 새 학생이나 새 수업에 미리 채워집니다(학생마다 정한 수업료가 있으면 그것이 우선). 통화는 금액을 보여 주는 방식(₩, $, £, €, ¥ …)만 바꾸고, 이미 저장된 숫자는 환산하지 않습니다. 통화나 시간대를 바꾸면 앱이 다시 열립니다.
편집 창에 항목이 없어요
편집 창에는 항상 모든 항목이 나옵니다. 사용자 항목의 숨기기는 목록의 열에만 적용됩니다. 그래도 없다면 파일이 옛 버전인지 확인하세요.
파일을 새 버전으로 바꾸면 데이터는 어떻게 되나요?
같은 컴퓨터, 같은 브라우저라면 그대로 남습니다 — 데이터는 파일이 아니라 브라우저에 있습니다. 클라우드 동기화를 켜 두었다면 클라우드에도 사본이 있습니다. 안전하게 바꾸기 전에 내보내기를 해 두세요.
지운 것이 잠시 뒤에 다시 나타나요
옛 버전의 버그로, 지금 버전에서는 고쳐졌습니다. 그래도 생긴다면 다른 기기에서 옛 버전 파일이 열려 있는지 확인하세요 — 모든 기기가 같은 최신 주소(amber67-git.github.io/classdesk)를 써야 합니다.
실수로 지웠어요
지운 직후 화면 아래에 되돌리기 버튼이 6초 동안 나타납니다. 놓쳤다면 백업 파일을 가져오기해서 되살릴 수 있습니다.
